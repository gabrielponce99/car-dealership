#  Car Dealership

An app that helps the user to track the available vehicles in the inventory, shows the type of vehicle 
and add or remove vehicles as well from the inventory list.

## Features

- Finds vehicle in a price range.
- Finds make or model of the vehicle.
- Finds vehicle in a year range.
- Finds vehicle by color.
- Finds vehicle in a mileage range.
- Finds type of the vehicle.
- Shows a list of available vehicles from a file.
- Add or remove vehicles from the list!
